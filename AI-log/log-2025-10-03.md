## Prompt Summary
Enhance `stripUnchangedFields` extension method to support deep comparison for nested maps and lists.

## Actions Taken
- Updated `lib/core/extension/map_extension.dart`:
  - Enhanced `stripUnchangedFields()` to recursively handle nested `Map<String, dynamic>` objects
  - Added deep comparison for `List` objects at any nesting level
  - Added `_areListsEqual()` helper method for recursive list comparison
  - Handles new keys that don't exist in original map
  - Updated documentation with nested map example
  - Supports arbitrary nesting depth (maps within maps, lists within maps, maps within lists, etc.)

**Enhanced Capabilities:**
- **Nested Maps**: Recursively compares nested map structures and returns only changed nested fields
- **Lists**: Deep comparison of list contents including nested maps and lists within lists
- **Mixed Structures**: Handles complex JSON-like structures with any combination of maps, lists, and primitives
- **Smart Diffing**: For nested maps, returns only the changed nested fields (not the entire parent object)
- **New Fields**: Automatically includes fields that exist in altered but not in original

**Example Use Cases:**
```dart
// Nested map comparison
final original = {'user': {'name': 'John', 'age': 30}};
final altered = {'user': {'name': 'John', 'age': 31}};
final diff = altered.stripUnchangedFields(original);
// Result: {'user': {'age': 31}} - only changed nested field

// List comparison
final original = {'tags': ['a', 'b', 'c']};
final altered = {'tags': ['a', 'b', 'd']};
final diff = altered.stripUnchangedFields(original);
// Result: {'tags': ['a', 'b', 'd']} - entire list included if any item changed
```

**Benefits:**
- More accurate PATCH payloads for complex nested data structures
- Reduces payload size by excluding unchanged nested objects
- Handles real-world API scenarios with nested JSON structures
- Maintains backward compatibility with simple flat maps
- No breaking changes to existing usage
